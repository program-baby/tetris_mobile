# Pixel Arcade / Block Battle 改善メモ

## 直近で対応したこと

- GitHub Pages入口を `Pixel Arcade` として整理
- アプリ本体と設定を `tetris/` 配下へ集約
- GitHub Pages Actions公開を追加
- Firebase対戦ルームのLive Rooms表示を入口に追加
- 古い対戦ルームが観戦可能として残る問題を修正
- テスト用のBGMプレビューページを削除
- Pixel Arcadeとゲーム本体に問題報告リンクを追加

## 次に改善したいこと

- Live Roomsに最終更新時刻を表示する
- 古いルーム掃除の結果をユーザーにわかりやすく通知する
- GitHub Issuesにテンプレートを追加する
- Playwrightのローカル実行後に終了待ちが残る原因を継続調査する
- Pixel Arcade側にランキング上位だけを軽く表示する
- Firebase無料枠の使用状況をより正確に見える化する
