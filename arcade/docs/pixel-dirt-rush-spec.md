# Pixel Dirt Rush 仕様書

## 目的

Pixel Arcade の2本目として、短時間で遊べるレトロな横スクロール・モトクロスタイムアタックゲームを追加する。

最初の目標は、ランキングやオンライン機能よりも、スマホとPCで1コースを最後まで遊べるMVPを完成させること。

## ゲーム概要

- タイトル: Pixel Dirt Rush
- ジャンル: 横スクロール / レース / タイムアタック
- プレイ時間: 30秒から60秒程度
- プレイ人数: 1人
- 対応環境: PC / スマホ
- 保存: localStorage に自己ベストを保存
- ランキング: MVP後に Firebase 対応予定

## 操作

### PC

| 操作 | キー |
| --- | --- |
| アクセル | 右 / D |
| ジャンプ | Space |
| 前傾 | 下 / S |
| 後傾 | 上 / W |

ブレーキはMVPでは省略する。必要になったら左 / A で追加する。

### スマホ

画面下に固定操作パネルを置く。

左側:

- 後傾
- 前傾

右側:

- JUMP
- GO

ボタンは44px以上にし、押しっぱなし入力に対応する。

## ゲームルール

- プレイヤーはスタート地点からゴールまで走る
- タイマーはスタート操作で開始
- ゴールラインを超えたらタイム確定
- 転倒してもゲームオーバーにはしない
- 転倒時は2秒間操作不能
- 復帰地点は少し手前の安全な地面
- 自己ベストを更新したら localStorage に保存

## 障害物

MVPで入れる障害物:

- ramp-small: 小ジャンプ台
- ramp-large: 大ジャンプ台
- bump: 段差
- mud: 減速床
- tire: 接触すると転倒しやすい障害物
- gap: 穴

最初の実装では、すべて矩形または線分ベースの簡易判定にする。

## バイク挙動

MVPではリアル物理ではなく、ゲーム向けの簡易物理にする。

状態:

- x
- y
- vx
- vy
- angle
- angularVelocity
- grounded
- crashed
- crashUntil

基本挙動:

- GO入力中は横速度を上げる
- 空中では重力で落下する
- JUMP入力は接地中のみ有効
- 前傾 / 後傾で角度を変える
- 着地角度が大きすぎると転倒
- 泥道では最大速度を下げる

## 転倒条件

- 着地時の角度が一定以上
- タイヤ障害物に強く接触
- 穴に落ちる
- バイク角度が一定以上

MVPの初期値:

- 転倒角度: 55度以上
- 転倒ペナルティ: 2000ms

## 実装ステップ

### Step 1: 画面の土台

- `games/pixel-dirt-rush/` を作成
- Canvasを表示
- HUDを表示
- スマホ操作ボタンを配置
- 背景と地面を描画

完了条件:

- ブラウザでゲーム画面が表示される
- Pixel Arcadeから遷移できる

### Step 2: バイク操作

- バイクを表示
- GOで前進
- JUMPで跳ぶ
- 前傾 / 後傾で姿勢変更

完了条件:

- PCとスマホで操作できる
- 空中と接地の違いがある

### Step 3: コースと障害物

- course01を作る
- 横スクロールを追加
- ジャンプ台、段差、泥道、タイヤ、穴を追加

完了条件:

- ゴールまで走れる
- 障害物がゲームに影響する

### Step 4: 転倒と復帰

- 転倒判定
- 2秒ペナルティ
- 手前から復帰

完了条件:

- 転倒しても最後まで遊べる

### Step 5: タイムとベスト

- タイマー
- ゴール判定
- リザルト表示
- localStorageベスト保存

完了条件:

- クリアタイムが表示される
- 自己ベストが残る

### Step 6: Pixel Arcade統合

- Pixel Arcadeにゲームカード追加
- Pages workflowの公開対象に追加
- E2Eの最低限チェック追加

完了条件:

- GitHub Pages入口から起動できる
